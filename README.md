# The Grundy domination number is not multiplicative on strong products

Brešar, Bujtás, Gologranc, Klavžar, Košmrlj, Patkós, Tuza and Vizer conjectured that
γ_gr(G ⊠ H) = γ_gr(G) γ_gr(H) for all graphs G and H (*Dominating sequences in grid-like and
toroidal graphs*, Electron. J. Combin. 23(4) (2016), #P4.34,
[doi:10.37236/6269](https://doi.org/10.37236/6269), Conjecture 22). The inequality ≥ always holds,
and equality was known when G is a forest (Bell, Driscoll, Krop and Wolff,
[doi:10.37236/9507](https://doi.org/10.37236/9507)). A claimed proof for all graphs, arXiv:2212.04565,
was withdrawn by its authors. This repository shows that the conjecture is false.

Let H_N be the graph on {0, …, N − 1} in which u and v are adjacent when |u − v| ≡ 2 (mod 3), and let
K_{2,2,2} be the octahedron.

| | Statement | Proof |
|---|---|---|
| Theorem 1.2 | γ_gr(K_{2,2,2}) = 2, γ_gr(H_21) = 10 and γ_gr(K_{2,2,2} ⊠ H_21) ≥ 21 > 2 · 10 | by hand, except γ_gr(H_21) ≤ 10: exhaustive search, certified in Lean 4 |
| Proposition 3.1 | γ_gr(K_{2,2,2} ⊠ H_N) ≥ N for every N; more generally for every H with an ordering and a 3-colouring t such that t(u) ≡ t(v) + 1 (mod 3) on every edge u < v | by hand |
| Theorem 1.3 | γ_gr(H_N) = ⌊(N + 1)/3⌋ + 3 for 6 ≤ N ≤ 63, so K_{2,2,2} ⊠ H_N is a counterexample for 21 ≤ N ≤ 63, with ratio up to 21/16 | exhaustive search (C; Python for N ≤ 24) |
| Proposition 2.2 | H_{3n} is the circular clique K_{3n/(n+1)} plus a perfect matching | by hand |
| Remark 5.3 | γ_gr(K_{3n/(n+1)}) = n + 4 for 3 ≤ n ≤ 11, so K_{2,2,2} ⊠ K_{27/10} (a circulant second factor) is a counterexample too | exhaustive search (Python) |

The sequence ((j mod 3), j), j = 0, …, 20, is legal in K_{2,2,2} ⊠ H_21: its j-th vertex footprints
((j + 1 mod 3) + 3, j), where t + 3 is the antipode of t in the octahedron. A longest legal sequence
of H_21 is 0, 3, 6, 9, 12, 19, 14, 2, 15, 1.

Open: whether γ_gr(H_N) = ⌊(N + 1)/3⌋ + 3 for every N (which would push the ratio to 3/2), and
whether the ratio γ_gr(G ⊠ H)/(γ_gr(G) γ_gr(H)) is bounded at all.

## Verification

The Lean 4 development (`lean/`, Lean v4.34.1, no Mathlib) proves the counterexample from first
definitions of legal sequences, of the three graphs and of the strong product:

| Lean theorem | Statement |
|---|---|
| `GrundyStrong.legal_length_le` | soundness of the layer certificate, for every graph (Lemma 4.2) |
| `GrundyStrong.oct_grundy` | γ_gr(K_{2,2,2}) = 2 |
| `GrundyStrong.H_grundy` | 0, 3, 6, 9, 12, 19, 14, 2, 15, 1 is a dominating legal sequence of H_21, and no legal sequence is longer |
| `GrundyStrong.prodSeq_legal`, `prodSeq_dominating` | the sequence of length 21 in the product |
| `GrundyStrong.strong_product_counterexample` | all of it together, with 2 · 10 < 21 |

The upper bound γ_gr(H_21) ≤ 10 is a certificate of 5479 dominated sets, generated by
`scripts/gen_layers.py`, stored as binary search trees in `lean/GrundyStrong/Layers.lean` and
checked by the kernel (`decide +kernel`; no `native_decide`). `lean/Check.lean` prints the axioms of
all 25 theorems; `scripts/audit_axioms.py` checks that only the standard axioms occur (they use
`propext` and `Quot.sound`, five use none; `verification/axioms.txt`).

Independent checks (`scripts/run_all.sh`, C and Python 3):

- `verification/c/grundy_bfs.c`: γ_gr by breadth-first search over dominated sets, for the
  octahedron and for H_N, 6 ≤ N ≤ 45 in CI (the paper's table to N = 63 is in
  `verification/grundy_HN.txt`).
- `verification/python/check_counterexample.py`: everything from edge sets — γ_gr of the
  octahedron by trying every sequence, γ_gr(H_N) for N ≤ 24 by memoised depth-first search, the
  product sequences for 21 ≤ N ≤ 36 from the definition of the strong product, Proposition 2.2 for
  n ≤ 30, and the circular cliques of Remark 5.3.
- `verification/python/check_lean_data.py`: the masks, layers and sequences written into the Lean
  files are the closed neighbourhoods, reachable dominated sets and sequences of the paper.

## Layout

```
lean/                     Lean 4 (v4.34.1, no Mathlib)
  GrundyStrong/           Basic (definitions), Search (certificate soundness), Layers (data), Counterexample
  Check.lean              axiom audit
verification/c/           grundy_bfs.c
verification/python/      check_counterexample.py, check_lean_data.py
verification/             axioms.txt, grundy_HN.txt
preprint/                 the paper (amsart) and its TikZ figures
dist/                     the paper as PDF, as LaTeX with PNG figures, and as an arXiv tarball
scripts/                  gen_layers.py, audit_axioms.py, run_all.sh, build_paper.sh
PRIORITY-CHECK.md         the dated check that nobody had disproved the conjecture before
```

To reproduce: `scripts/run_all.sh`, `cd lean && lake build && lake env lean Check.lean`, and
`scripts/build_paper.sh` (TeX Live). The workflow `.github/workflows/verify.yml` runs all three on
every pull request.
